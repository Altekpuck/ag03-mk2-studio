# Journal des versions

## 0.1.0 (2026-11-01)

Première version.

- AG03 MK2 Studio : application graphique en une seule vue (canaux 1 et 2, reverb), potards, saisie au clavier,
  courbe d'EQ interactive, profils intégrés et personnels, reconnexion automatique.
- Réglage libre, calcul identique à AG Controller : EQ 4 bandes, coupe-bas, compresseur, filtres de la reverb,
  amortissement de la reverb ; durée de reverb à 1,5 % près.
- Presets d'AG Controller : voix, instruments, ampli, reverb.
- ag03ctl : outil en ligne de commande.
- Installeur Windows signé Lopjoy.
- Linux : compile, pas encore testé avec le boîtier.
